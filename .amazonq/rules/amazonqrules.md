Error Handling

Code Consistency

Follow the existing coding style, folder structure, and naming conventions in my project.

If style or structure is missing, ask me before introducing a new one.

Safety and Versioning

Always remind me to back up or commit my work before making major changes.

Communication

Optimization & Learning
